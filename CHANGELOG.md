# Changelog

All versions were built and tried on 2026-10-10 against Obsidian 1.14.4 on macOS.

## 0.2.5

- Groups: "+ Add group" button, and an empty group now stays a group instead of showing as a section.
- Clicking a group opens or closes it.
- Sections and groups can be dragged into a group, or onto the empty space below the list to leave one.
- Right-click menu for groups, with "New group inside" and "Move out of ...".

## 0.2.4

- "New subpage" in the page right-click menu.
- Five indent levels instead of three.

## 0.2.3

- Fixed: after a freeform page had been shown in a tab, the next normal note opened in that tab
  was displayed as a freeform page, and editing it there wrote a box marker into the note.

## 0.2.2

- "Open as freeform page" button on the Markdown view of a freeform page.
- Boxes can be resized from the bottom edge and the corner, with an optional stored height.

## 0.2.1

- Fixed: releasing a drag over empty space created a stray empty box.
- Removed an unnecessary horizontal scrollbar on freeform pages.

## 0.2.0

- Freeform pages: click to type, Markdown boxes, move and resize, image paste and drop,
  convert to and from normal pages.

## 0.1.1

- Clicking a page keeps keyboard focus in the page list, so Tab indents the page instead of
  typing a tab into the note.

## 0.1.0

- Two-pane navigation: colored sections, hand-ordered pages, three indent levels, collapsible
  subpages, drag to reorder, remembered state.
